# EC2 (Elastic Compute Cloud)

Servicio que proporciona capacidad de cómputo escalable en la nube mediante instancias de servidores virtuales configurables.

- **Instancia EC2** -> AMI (S.O.) + Tamaño de la Instancia (CPU + RAM) + Almacenamiento + Grupos de Seguridad + Datos de Usuario EC2.
- **Grupos de seguridad** -> Firewall adjunto a la instancia EC2.
- **Datos de Usuario EC2** -> Script lanzado en el primer arranque de una instancia para configurar los parámetros necesarios.
- **SSH** -> Iniciar una terminal en nuestras instancias EC2 (puerto 22).
- **Rol de la Instancia EC2** -> Enlace a los roles de IAM.
- **Opciones de compra**:
  - **On-Demand**: Pago por hora/segundo.
  - **Spot**: Hasta 90% más barato, pero puede interrumpirse.
  - **Reservada**: Hasta 72% más barato por compromiso de 1 o 3 años.
  - **Host Dedicado**: Servidor físico dedicado a ti.
  - **Instancia Dedicada**: Instancias en hardware dedicado, pero sin control total del servidor físico.

## Almacenamiento de Instancias EC2

- **Volúmenes EBS**: Volumen de disco persistente para instancias.
  - Unidades de red adjuntas a una instancia EC2 a la vez.
  - Asignados a una zona de disponibilidad.
  - Puede utilizar EBS Snapshot para copias de seguridad / transferir volúmenes EBS a través de AZ.
- **AMI**: Crea instancias EC2 listas para usar con nuestras personalizaciones.
- **EC2 Image Builder**: Construye, prueba y distribuye automáticamente AMIs.
- **EC2 Instance Store**: Almacenamiento de bloques temporal pero de muy alto rendimiento.
  - Se pierde si nuestra instancia se detiene/termina.
- **EFS** -> Sistema de archivos en red, se puede adjuntar a 100 instancias en una región.
- **EFS-IA** -> Clase de almacenamiento de coste optimizado para archivos de acceso poco frecuente.
- **FSx para Windows** -> Sistema de archivos en red para Windows.
- **FSx para Lustre** -> Sistema de archivos en red para Linux.
