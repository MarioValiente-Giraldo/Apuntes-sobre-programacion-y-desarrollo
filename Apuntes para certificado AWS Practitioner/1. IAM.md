# IAM (Identity and Access Management)

Es un servicio que permite gestionar usuarios, grupos, roles y permisos para controlar el acceso seguro a los recursos de AWS.

- **Usuarios** -> Usuario físico que tiene una contraseña para acceder a la consola.
- **Grupos** -> Contiene sólo usuarios.
- **Políticas** -> Documento JSON que describe los permisos para los usuarios o grupos.
- **Roles** -> Para instancias EC2 o servicios AWS.
- **Seguridad** -> MFA + política de contraseñas.
- **AWS CLI** -> Gestiona tus servicios mediante línea de comandos.
- **AWS SDK** -> Gestiona tus servicios mediante un lenguaje de programación.
- **Claves de acceso** -> Accede a AWS mediante CLI o SDK.
- **Auditoría** -> Informe de credenciales de IAM y Asesor de acceso IAM.
