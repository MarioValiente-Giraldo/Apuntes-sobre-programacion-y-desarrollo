# Bases de Datos y Análisis en AWS

## Bases de datos relacionales (OLTP)

- RDS y Aurora, servicio propio de AWS.

## Diferencias entre Multi-AZ, Réplica de Lectura y Multi-Región

- **Multi-AZ** -> Réplica de la BD en otra zona de disponibilidad de la misma región.
- **Réplica de lectura** -> Copia asíncrona de la BD que solo se puede leer.
- **Multi-Región** -> Combina réplicas de lectura entre distintas regiones geográficas.

## Bases de datos en memoria (in-memory)

- **ElastiCache**: guarda los resultados que más se piden en memoria para caché.

## Otros servicios de datos

- **Base de datos clave/valor** -> DynamoDB (sin servidor) y DAX (caché para DynamoDB).
- **Warehouse - OLAP** -> Redshift (SQL), BD para análisis y consultas sobre volúmenes de datos (Big Data).
- **Cluster Hadoop** -> EMR.
- **Athena** -> Consulta de datos en Amazon S3 (sin servidor y SQL).
- **QuickSight** -> Dashboards sobre tus datos (sin servidor).
- **DocumentDB** -> "Aurora para MongoDB" (JSON - BD noSQL).
- **Amazon QLDB** -> Libro de transacciones financieras.
- **Amazon Managed Blockchain** -> Cadenas de bloques Hyperledger y Ethereum.
- **Glue** -> Servicio gestionado de ETL (Extract - Transform - Load) y Catálogo de Datos.
- **Database Migration Service** -> DMS.
- **Neptune** -> Base de datos gráfica.
