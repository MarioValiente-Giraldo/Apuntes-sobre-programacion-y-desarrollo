# Amazon S3 (Simple Storage Service)

Servicio de almacenamiento de objetos escalable, duradero (99.999999999%) y de bajo costo, organizado en buckets.

- **Buckets vs Objetos** -> Nombre único global, ligado a una región.
- **Seguridad de S3** -> Política de IAM, política de bucket S3 (acceso público), cifrado S3.
- **Sitios web de S3** -> Aloja un sitio web estático en Amazon S3.
- **Versionado de S3** -> Múltiples versiones de archivos, para evitar borrados accidentales.
- **Replicación de S3** -> En la misma región o entre regiones, se debe activar el control de versiones.
- **Clases de almacenamiento S3**:
  - Standard
  - IA (acceso infrecuente)
  - One Zone - IA
  - Intelligent -> Mover objetos según conveniencia con Machine Learning.
  - Glacier -> Instant - Flexible - Deep.
- **Familia Snow** -> Importar datos a S3 a través de un dispositivo físico, permitiendo hacer computación de borde (edge computing).
- **OpsHub**: Aplicación de escritorio para gestionar los dispositivos de la Familia Snow.
- **Storage Gateway** -> Servicio híbrido que conecta infraestructura local con almacenamiento en la nube S3.
